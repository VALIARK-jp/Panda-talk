# パンダイトーク 画面構成案

要件定義書 v0.3に基づき、以下の主要5画面を構築します。

## 1. ホーム（回答フィード）
- **役割**: 二択質問に回答するメイン画面。
- **要素**: 
  - 本日の二択カード（質問文、選択肢A/B）
  - 回答後の統計表示（%）
  - パンダのリアクションメッセージ
  - ボトムナビゲーション

## 2. マッチ（合致度ランキング）
- **役割**: 価値観の合うユーザーや真逆なユーザーを見つける。
- **要素**:
  - 合致度ランキング（「ほぼ同じパンダ」「真逆パンダ」などのラベル表示）
  - ユーザーカード（名前、合致度%、共通回答数）
  - フォロー/友達申請ボタン

## 3. 投稿
- **役割**: 新しい二択質問を作成する。
- **要素**:
  - 質問文入力フォーム
  - 選択肢A/B入力フォーム
  - カテゴリ選択（恋愛、食、ネタなど）
  - 投稿プレビュー

## 4. トーク（コミュニティ）
- **役割**: 価値観の近い（または遠い）グループでの交流。
- **要素**:
  - 参加可能なグループ提案（「ほぼ同じパンダ部屋」など）
  - 平均合致度の表示
  - グループ一覧

## 5. プロフィール
- **役割**: 自分の回答履歴と傾向の確認。
- **要素**:
  - ステータス（回答数、投稿数）
  - 自分の価値観傾向（匿名集計データとの比較）
  - 友達一覧へのリンク

## デザインの方向性
- **配色**: #111111（Black）と #FFFFFF（White）をベースにしたモノトーン。
- **造形**: 大きめの角丸、広い余白、親しみやすいパンダのイラスト。
- **雰囲気**: スタイリッシュながら「かわいい」が共存するNotion風のクリーンなUI。

この構成でよろしければ、デザインシステムの構築を開始します。
