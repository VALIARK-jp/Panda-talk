# ユースケース一覧

アクターは2種類。
- **ゲスト**: 未登録ユーザー（Stage 0）
- **ユーザー**: 登録済みユーザー（Stage 1）

---

## 認証

| ID | ユースケース | アクター | 説明 |
|---|---|---|---|
| UC-A01 | アプリを起動する | ゲスト | オンボーディング画面を表示する |
| UC-A02 | 新規登録する | ゲスト | Google/Appleで登録。ゲスト時のローカルデータをDBに移行する |
| UC-A03 | ログインする | ゲスト | Google/Appleで既存アカウントにログイン |
| UC-A04 | ログアウトする | ユーザー | セッションを破棄。push_tokensからデバイストークンを削除 |
| UC-A05 | アカウントを削除する | ユーザー | 全データを削除してアカウントを退会する |
| UC-A06 | ログイン導線を開く | ゲスト | 画面右上のログインボタン、またはゲスト状態のプロフィールタブからログイン画面を開く |

## 診断フィード

| ID | ユースケース | アクター | 説明 |
|---|---|---|---|
| UC-F01 | 未回答の質問を取得する（診断タブ） | ゲスト・ユーザー | 投稿順（created_at ASC）で未回答の質問を取得する |
| UC-F02 | 盛り上がっている質問を取得する（Hotタブ） | ゲスト・ユーザー | いいね数+コメント数の多い質問を取得する |
| UC-F03 | 質問に回答する | ゲスト | 回答をローカルに保存する |
| UC-F04 | 質問に回答する | ユーザー | 回答をDBに保存する。match_scoreをインクリメンタル更新する |
| UC-F05 | 回答後の統計を見る | ゲスト・ユーザー | 選択肢ごとの回答比率を取得して表示する |
| UC-F06 | 少数派/多数派を確認する | ゲスト・ユーザー | 自分の回答が多数派か少数派かを判定する |
| UC-F07 | 異端児スコアを確認する | ゲスト・ユーザー | 累計回答数と少数派回答数からスコアを計算して表示する |
| UC-F08 | 回答をシェアする | ゲスト・ユーザー | 「私は〇〇派！」のテキストをOSのシェアシートで共有する |
| UC-F09 | 過去の回答履歴を見る | ユーザー | 自分が回答済みの質問一覧を表示する |
| UC-F10 | 登録誘導を受ける | ゲスト | 10問ごとにモーダルを表示する。閉じることもできる |

## 質問投稿

| ID | ユースケース | アクター | 説明 |
|---|---|---|---|
| UC-Q01 | 質問を投稿する | ユーザー | 二択質問（text / optionA / optionB / category）を投稿する |
| UC-Q02 | 類似質問を検索する | ユーザー | 投稿前にキーワードで既存質問を検索して重複を防ぐ |
| UC-Q03 | 質問を編集する | ユーザー | 自分が投稿した質問のtext/optionA/optionB/categoryを更新する |
| UC-Q04 | 質問を削除する | ユーザー | 自分が投稿した質問を削除する。紐づくanswers/comments/likesも連鎖削除する |

## 友達

片方だけの一方的なフォローは持たない。双方の承認が取れた場合のみ友達になる。

| ID | ユースケース | アクター | 説明 |
|---|---|---|---|
| UC-FR07 | ユーザーをusernameで検索する | ユーザー | @usernameの前方一致で候補を表示する。結果からプロフィールを開き友達申請の起点にする |
| UC-FR01 | 友達申請を送る | ユーザー | friendshipsにレコードを追加する。相手にお知らせを送る |
| UC-FR02 | 友達申請を承認する | ユーザー | friendshipsを承認済みに更新する。申請者にお知らせを送る |
| UC-FR03 | 友達申請を断る | ユーザー | friendshipsのレコードを削除する |
| UC-FR04 | 友達一覧を見る | ユーザー | 相互承認済みの友達一覧を取得する |
| UC-FR05 | 友達を解除する | ユーザー | friendshipsのレコードを削除する |
| UC-FR06 | 回答を比較する | ユーザー | 友達・マッチユーザーと回答を並べて比較する |
