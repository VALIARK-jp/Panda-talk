# コンセプト・ビジョン

## サービス概要

- **サービス名**: パンダトーク
- **カテゴリ**: 価値観マッチングSNS / 診断SNS / コミュニティSNS
- **コンセプト**: 白黒つけるほど、仲良くなるSNS。

## ビジョン

「人間関係の検索エンジンを作る」

現在のSNSは見た目・フォロワー数・写真・肩書きで人間関係が構築されている。  
パンダトークでは **感覚・価値観・思考** をベースに人間同士を繋ぐ。

## 世界観

白黒・二択・パンダをUI/UX/ブランド全体に統一する。  
「どっち派？」という体験そのものを世界観に落とし込む。

## ターゲット

### 初期ターゲット
- 大学生（特に阪大からスタート）
- MBTIや診断文化に親和性がある層
- 恋愛・友達・価値観診断が好きなSNSネイティブ

### 拡張ターゲット
- 高校生
- 若手社会人
- 恋愛目的ユーザー
- コミュニティ探索ユーザー
- 採用・マッチング用途

## 競合との差別化

### vs MBTI
| | MBTI | パンダトーク |
|---|---|---|
| 質問 | 固定 | 無限・ユーザー生成 |
| タイプ | 固定16種 | 常に進化 |
| SNS性 | なし | あり |

### vs X / Instagram
| | 既存SNS | パンダトーク |
|---|---|---|
| 中心軸 | 発信・承認欲求 | 価値観・合致度 |
| 人間関係 | フォロワー数 | 共通回答数 |

## 最重要ポイント

- ❌ 診断アプリではない
- ❌ MBTIコピーではない
- ✅ 人間関係SNS
- ✅ 価値観データプラットフォーム
- ✅ 人間の感覚を可視化するSNS

## 最終目標

> 「この人、自分とめっちゃ合う」を世界で一番自然に発見できるプラットフォームを作る。
> 人間関係を"感覚データ"で再定義する。
