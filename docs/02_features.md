# 機能仕様

## コア機能一覧

### 1. 無限二択診断

ユーザーが無限に増える二択質問へ回答する。

**質問例:**
- 朝型？夜型？
- 追う恋愛？追われる恋愛？
- 計画派？ノープラン派？
- 友達は少人数派？大人数派？
- 就職は安定？挑戦？

---

### 2. 合致度システム

回答履歴からユーザー同士の合致度を算出する。

```
合致度 = 同じ回答数 / 共通回答数
```

**例:**
```
共通回答：100問
一致：87問
→ 合致度 87%
```

---

### 3. 自動グループ生成

合致度をもとにシステムが自動で3人グループを生成する。**3人全ペア（3C2=3組）** が条件を満たす場合のみ成立。

| グループ種別 | 条件 | コンセプト |
|---|---|---|
| high_match | 全ペアの合致度が高い | 似た者同士 |
| middle_match | 全ペアの合致度が50%付近 | 微妙に合う |
| low_match | 全ペアの合致度が低い | 真逆同士 |

> 「逆に合わないから面白い」

---

### 4. 匿名コメント

質問ごとにどっち派かを示した上で匿名コメントを投稿できる。

**表示イメージ:**
```
朝型？夜型？

[朝型派]              [夜型派]
「朝の静けさ最高」    「夜の方が集中できる」
```

---

### 5. 匿名キャリア分析

合致度が高い人たちの志望業界・バイト・インターン・就職先傾向を匿名集計として表示。

**表示例:**
```
あなたと85%以上合う人の傾向

IT：32%
広告：18%
教育：14%
```

## ユーザーステージ設計

### Stage 0: 未登録（ゲスト）
**ローカルのみで完結。DBへの書き込みなし。**

- 質問に回答できる（ローカル保存）
- 回答後に白黒統計を見られる（統計取得APIは認証不要）
- 凡人/異端児スコアを見られる（ローカル計算）
- 10問ごとに登録誘導カード（モーダル）を表示

**登録誘導カードのメッセージ:**

| タイミング | メッセージ |
|---|---|
| 10問 | 登録すると合致度が見られるよ |
| 20問 | あなたと合う人、もう見つかってるかも |
| 30問 | 異端児スコアが本格的になってきた。記録しよう |

- 強制ではなく「続ける」で閉じられる

### Stage 1: 登録済み
**登録時にローカルデータをDBに一括移行。**

- ゲスト時の回答をDBに保存
- 合致度・マッチ機能が解放
- フォロー・友達・チャット機能が解放
- 投稿・コメント機能が解放

## 凡人/異端児スコア

各問の**最新**の A/B 票数で多数派／少数派を判定し、少数派だった割合を出す。

```
異端児スコア = 少数派だった回答数 / 総回答数 × 100

判定（1問ごと）:
- その問の回答が1件だけ → 多数派（スコアに効く）
- A/B 同票 → どちらも多数派
- それ以外 → 選んだ側の票数が相手より少なければ少数派
```

他の人が後から答えると、過去の自分の回答が少数派↔多数派に変わりうる（スコアも変動）。

**正:** DB ビュー `panda_user_oddball_scores`（プロフィール）。**UI のバッジ等:** 同じルールを `lib/core/oddball_score.dart` で共有。

**表示イメージ:**
```
あなたの異端児スコア

　26%
凡人 ████░░░░░░ 異端児

30問中8問で少数派の回答をしました
```

### プッシュ通知設計

| 通知種別 | トリガー | 本文例 |
|---|---|---|
| いいね | 自分の質問にいいね | 「〇〇さんがあなたの質問にいいねしました」 |
| コメント | 自分の質問にコメント | 「〇〇さんがコメントしました」 |
| 友達申請 | 申請受信 | 「〇〇さんから友達申請が届きました」 |
| 友達承認 | 申請承認 | 「〇〇さんと友達になりました」 |
| 新規マッチ | 高合致ユーザー出現 | 「あなたと90%以上合う人が現れました」 |
| グループ生成 | 自動グループ追加 | 「新しいパンダ部屋が作られました」 |

**実装方式:**
- Firebase Cloud Messaging（FCM）を初期から採用
- デバイストークンを `push_tokens` テーブルに保存
- `notifications` テーブルへの INSERT を Supabase Database Webhook でフック
- Webhook → Supabase Edge Function（TypeScript）→ FCM API → iOS(APNs) / Android に配信
- Flutter側は `firebase_messaging` パッケージでトークン取得・受信処理

**起動状態別の挙動:**
| 状態 | 挙動 |
|---|---|
| フォアグラウンド | アプリ内バナー表示 |
| バックグラウンド | OSのプッシュ通知として表示 |
| 終了中 | OSのプッシュ通知として表示・タップでアプリ起動 |

## いいね機能

質問カードに対していいねできる。

- 1ユーザー1質問につき1いいね（UNIQUE制約）
- いいね数はHotタブのランキング算出に使用
- 自分の質問にいいねされるとお知らせに通知

---

## お知らせ機能

以下のイベントをお知らせとして受信する。

| 種別 | トリガー |
|---|---|
| いいね | 自分の質問にいいねされた |
| コメント | 自分の質問にコメントされた |
| 友達申請 | 友達申請が来た |
| 友達承認 | 自分の申請が承認された |
| 新規マッチ | 高合致ユーザーが現れた |
| グループ生成 | 自動グループに追加された |

- 未読件数をバッジ表示
- タップで該当コンテンツへ遷移
- 既読化は一括 or 個別

## 診断フィードのタブ設計

### 診断タブ
- 全ユーザー共通の投稿順（created_at ASC）で未回答の質問を順番に表示
- 純粋に「次の問題」を答え続けるモード

### Hotタブ
- 回答数・コメント数が多い「盛り上がってる」質問を表示
- フォロー中 / 友達が投稿した質問を表示
- 回答済み・未回答問わず表示
- ここで答えた質問は診断タブの順番でスキップ（既回答）扱いになる

## シェア機能

バイラル拡散の起点となるシェアを各画面に設置。

| シェア種別 | 設置場所 | シェアテキスト例 |
|---|---|---|
| 質問回答シェア | 回答結果画面 | 「私は〇〇派！（XX%）あなたはどっち？ #パンダトーク」 |
| プロフィールシェア | プロフィール画面 | 「パンダトークやってます！一緒に合致度測ろう #パンダトーク」 |
| 合致度シェア | ユーザー詳細画面 | 「〇〇さんと合致度XX%！価値観めっちゃ近い🐼 #パンダトーク」 |
| 異端児スコアシェア | プロフィール画面 | 「私の異端児スコアはXX%（凡人寄り/異端児寄り） #パンダトーク」 |
