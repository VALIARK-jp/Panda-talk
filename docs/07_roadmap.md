# 開発ロードマップ・KPI

## フェーズ1: MVP

### 実装スコープ
- [ ] ゲストモード（ローカル回答・統計閲覧・異端児スコア）
- [ ] 登録時のローカルデータDB一括移行
- [ ] ログイン（Supabase Auth / Google・Apple）
- [ ] 二択質問投稿
- [ ] 質問への回答（投稿順・全ユーザー固定）
- [ ] 回答後の白黒統計表示
- [ ] 凡人/異端児スコア表示
- [ ] 匿名コメント（choice付き）
- [ ] 合致度計算・表示（信頼度補正あり）
- [ ] フォロー機能
- [ ] 友達機能（2人ペア）
- [ ] 回答比較画面
- [ ] 1対1チャット

### KPI目標
- ユーザー数: 100人
- 1人あたり回答数: 100問
- DAU率: 40%以上
