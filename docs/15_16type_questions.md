# 16type 初回診断 — 質問・配点（正本）

- **投稿**: 運営アカウント「管理者パンダ」がアプリから通常投稿（他の質問と同じ `panda_questions`）。`question_number` は **1 始まりで連番**（新規は常に「今の最大 + 1」）。**物理削除すると後ろの番号が繰り上がる**（例: Q3 削除 → 旧 Q4 が Q3 に）。初回診断は **1〜16 番の質問**として判定するので、16本そろうまでこの順で投稿する
- **`category`**: 投稿画面と同じ分類（恋愛・生活・性格など）。**`16type` というカテゴリは使わない**。診断対象かどうかは `question_number` 1〜16 で判別する
- **フィードUI**: 初回16問フェーズだけ画面上部に進捗ゲージ（`n/16`・診断完了）。各問カードは通常質問と同じ（`Q.n`・カテゴリタグ・いいね・コメント等）。16問目回答後に結果モーダルのみ特別
- 配点: アプリ `lib/core/diagnosis_16_mapping.dart` にハードコード（DBには載せない）
- 4軸の第一極: 愛情=安心 / 思考=感情 / 行動=慎重 / 人生=理想

各軸の表示% = 第一極ポイント ÷ (第一極 + 第二極) × 100（同点は50%）
