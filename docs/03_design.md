## 画面設計

### ホーム画面

**回答フロー:**
```
質問カード表示（未回答）
    ↓ タップ or スワイプで回答
スプラトゥーン風アニメーション（2〜3秒）
    黒 ████████████░░░░░░ 白
    62%                  38%
    ↓ 自動で次の質問へ
次の質問カード
    ↑ 上スクロールで前の質問に戻れる（閲覧のみ・回答変更不可）
```

**質問カードUI仕様:**
- 白背景
- 角丸 24px
- 薄い影
- 大きめ文字（readable）

**選択肢ボタン:**
- 左ボタン = 常に白背景（option_a）
- 右ボタン = 常に黒背景（option_b）
- 回答前：左右それぞれ50%幅で固定
- 回答後：実際の回答比率に応じてボタン幅がアニメーションで変化
  ```
  例: 朝型62% / 夜型38%
  ┌──────────────────┬────────┐
  │        白        │  黒    │
  │       朝型       │  夜型  │
  │      62% 幅      │ 38%幅  │
  └──────────────────┴────────┘
  ```
- スキップ機能なし（必ずどちらかを選ぶ）

**過去の問題（上スクロール時）:**
- 自分が選んだ側のボタンに選択済みマーク（枠線・チェックなど）
- ボタン幅は現在の比率をそのまま表示
- 回答変更不可

**スクロール挙動:**
- 下スクロール → 次の未回答問題へ
- 上スクロール → 過去の回答済み問題を遡れる（無限スクロール）
- 回答済み問題は統計（黒白の割合）を表示したまま

---

### 検索画面

過去の全質問をキーワード検索できる。

**機能:**
- キーワードで質問を検索
- 未回答の問題はそのまま回答できる
- 回答済みの問題は統計のみ表示

---

### 投稿画面

**2つの機能を持つ:**

#### 1. 質問を作る
- 質問文・選択肢A・選択肢Bを入力して投稿
- 投稿した質問は全ユーザーのフィードに（投稿順で）流れる

#### 2. 既存質問を検索（重複防止）
- 投稿前に同じような質問がないか検索できる
- 重複投稿を防ぐためのUX

---
