
# パンダトーク 事業計画書

> 白黒つけるほど、仲良くなるSNS。

---

## 0. エグゼクティブサマリー

パンダトークは、ユーザーが無限の二択質問に答え続けることで価値観を数値化し、他ユーザーとの合致度をベースに人間関係を構築するSNSである。MBTIのような固定診断ではなく、ユーザー生成の質問が無限に増え続けるSNSとして差別化する。

- **サービス名**: パンダトーク
- **カテゴリ**: 価値観マッチングSNS
- **コンセプト**: 白黒つけるほど、仲良くなるSNS。
- **初期ターゲット**: 大学生（阪大からスタート）
- **技術スタック**: Flutter / Next.js / Hono + TypeScript / Supabase

---

## 1. ビジョン

### 「人間関係の検索エンジンを作る」

現在のSNSは見た目・フォロワー数・写真・肩書きで人間関係が構築されている。パンダトークでは **感覚・価値観・思考** をベースに人間同士を繋ぐ。

### 最終目標

> 「この人、自分とめっちゃ合う」を世界で一番自然に発見できるプラットフォームを作る。
> 人間関係を"感覚データ"で再定義する。

## 2. 競合との差別化

### vs MBTI
| | MBTI | パンダトーク |
|---|---|---|
| 質問 | 固定 | 無限・ユーザー生成 |
| タイプ | 固定16種 | 常に進化 |
| SNS性 | なし | あり |

| | 既存SNS | パンダトーク |

| 中心軸 | 発信・承認欲求 | 価値観・合致度 |
| 人間関係の軸 | フォロワー数 | 共通回答数 |

- ❌ MBTIコピーではない

- ✅ 価値観データプラットフォーム
- ✅ 人間の感覚を可視化するSNS

## 3. 機能仕様

### 3.0 ユーザーステージ設計

| ステージ | 条件 | できること |
|---|---|---|
| Stage 0（ゲスト） | 未登録 | 回答（ローカル保存）・統計閲覧・異端児スコア確認 |
| Stage 1（登録済み） | 登録後 | 合致度・マッチ・フォロー・友達・チャット・投稿 |

**ゲストのデータフロー:**
```
回答 → ローカル保存 → 登録 → DBに一括移行（POST /users/migrate）
```

統計取得APIは認証不要。FlutterもNext.js（Web）も同じHono APIを共有。

---

### 3.1 無限二択診断

ユーザーが投稿した二択質問に全ユーザーが **投稿順（固定順）** で回答していく。運営からの問題はなく、全てユーザー生成。

**質問例:**
- 朝型？夜型？
- 追う恋愛？追われる恋愛？
- 計画派？ノープラン派？
- 友達は少人数派？大人数派？
- 就職は安定？挑戦？

**回答フロー:**
```
質問カード表示
    ↓ タップ or スワイプで回答
スプラトゥーン風アニメーション（2〜3秒）
    黒 ████████████░░░░░░ 白
    62%                  38%
    ↓ 自動で次の質問へ
    ↑ 上スクロールで過去の問題に戻れる（閲覧のみ）
```

**フィード取得:** 未回答の問題を投稿順（created_at昇順）で表示

### 3.2 回答後統計表示

左ボタン=白（option_a）・右ボタン=黒（option_b）で色固定。回答前は50%/50%の幅。回答後にボタン幅が実際の比率にアニメーションで変化し、数秒後に自動で次の問題へ。

```
回答後:
┌──────────────────┬────────┐
│        白        │  黒    │
│       朝型       │  夜型  │
│      62% 幅      │ 38%幅  │
└──────────────────┴────────┘
```

過去の問題を遡ったとき、自分が選んだ側に選択済みマークが表示される。スキップなし。DBの追加テーブル不要。answersテーブルのインデックスで高速集計。

### 3.3 検索・投稿

**検索:** 過去の全質問をキーワード検索。未回答ならそのまま回答可能。

**投稿画面の2機能:**
- 質問を新規作成（投稿順で全ユーザーのフィードへ）
- 投稿前に既存の類似質問を検索（重複防止UX）

### 3.3 匿名コメント

質問ごとにどっち派かを示した上で匿名コメントを投稿できる。

```
朝型？夜型？

[朝型派]                [夜型派]
「朝の静けさ最高」      「夜の方が集中できる」
「早起きは三文の得」    「夜型は生産性高い」
```

### 3.4 合致度システム

回答履歴からユーザー同士の合致度を算出・キャッシュする。

**計算式:**
```
match_rate = same_answer_count / common_answer_count
```

**信頼度補正:**
```
display_score = match_rate * (common_answer_count / (common_answer_count + 50))
```

共通回答が少ないペアの高合致は信頼度が低いため、補正をかけてソートする。

**更新方式:** バッチではなく回答トリガーのインクリメンタル更新。ユーザーAが問題Qに回答した瞬間に、問題Qに回答済みの全ユーザーとのスコアを差分更新。

**マッチ表示ソート:**
| 表示 | ソート |
|---|---|
| 似た人 | display_score DESC |
| 真逆の人 | (1 - match_rate) * confidence DESC |
| 50%付近 | ABS(match_rate - 0.5) * confidence ASC |

### 3.5 友達（相互承認制）

一方的なフォローは持たない。双方が承認した場合のみ友達になる。

- 申請 → 承認 で友達成立
- 断る・解除はレコード削除
- 友達になると一部情報解禁・DMが可能になる

### 3.6 自動グループ生成（3人）

合致度をもとにシステムが自動で3人グループを生成。**3人全ペア（3C2=3組）** が全て条件を満たす場合のみ成立。

| グループ種別 | 条件 | 表示名 |
|---|---|---|
| high_match | 全ペアの合致度が高い | ほぼ同じパンダ部屋 |
| middle_match | 全ペアの合致度が50%付近 | なんか似てるパンダ部屋 |
| low_match | 全ペアの合致度が低い | 真逆パンダ部屋 |

### 3.7 チャット

- **1対1チャット**: 友達ペアでのダイレクトメッセージ
- **グループチャット**: 3人グループでのチャット

### 3.8 回答比較

友達・マッチしたユーザーと回答を並べて比較できる画面。

### 3.9 匿名キャリア分析（フェーズ2）

合致度が高い人たちの志望業界・就職先傾向を匿名集計として表示。

```
あなたと85%以上合う人の傾向

IT：32%
広告：18%
教育：14%
```

## 4. ブランド・UI設計

### ブランドトーン

**可愛い × スタイリッシュ × 白黒**

カラフルにはしない。余白・丸み・アニメーション・パンダキャラクターで可愛さを出す。

### カラーパレット

| 名前 | カラーコード |
|---|---|
| Black | `#111111` |
| White | `#FFFFFF` |
| Soft Gray | `#F5F5F5` |
| Border Gray | `#E5E5E5` |
| Text Gray | `#777777` |

**UIルール:** 白背景中心・黒文字・選択時のみ黒塗り・アクセントカラー禁止

### デザインキーワード
- 白黒 / 丸い / 軽い / ミニマル
- TikTok的テンポ感 / Notion的余白

### パンダキャラクター

案内役として軽くリアクションする。喋りすぎない。

```
白黒つけてこ。
この人かなり近いかも。
逆に合わなすぎて面白い。
もっと答えると精度が上がるよ。
```

## 5. 技術構成

| レイヤー | 技術 | 理由 |
|---|---|---|
| フロントエンド | Flutter | iOS/Android同時開発・アニメーション・MVP向き |
| バックエンド | Hono + TypeScript | 軽量・API開発高速・型安全 |
| DB | PostgreSQL（Supabase） | リレーション強い・合致度計算向き |
| 認証 | Supabase Auth | DBと同一基盤・メール/Apple対応 |
| インフラ | Supabase + Cloudflare | Auth・DB・Storageを一元管理 |
| プッシュ通知 | Firebase Cloud Messaging（FCM） | iOS/Android共通・APNs対応 |

## 6. DB設計（概要）

| テーブル | 役割 |
|---|---|
| users | ユーザー |
| questions | 二択質問（ユーザー投稿） |
| answers | 回答（ENUM: a/b） |
| comments | 匿名コメント（choice付き） |
| friendships | 友達申請・友達関係（相互承認制） |
| match_scores | 合致度キャッシュ（nC2・共通回答なしはレコードなし） |
| groups | 3人グループ（high/middle/low ENUM） |
| group_members | グループ所属 |
| messages | グループチャット |
| direct_messages | 1対1チャット |
| question_likes | 質問へのいいね |
| comment_likes | コメントへのいいね |
| notifications | お知らせ（いいね・コメント・友達・マッチ・グループ） |
| push_tokens | プッシュ通知用デバイストークン（FCM/APNs） |
